# zCreator

Offline reincarnation planner for ZombieMUD, for Windows, macOS and Linux. No installation, account or game connection is required.

## Download

**[Download the latest version](https://github.com/bogataj/zcreator-releases/releases/latest)**

| System | File |
| --- | --- |
| Windows | [zCreator-win-x64.zip](https://github.com/bogataj/zcreator-releases/releases/latest/download/zCreator-win-x64.zip) |
| macOS, Apple silicon | [zCreator-osx-arm64.zip](https://github.com/bogataj/zcreator-releases/releases/latest/download/zCreator-osx-arm64.zip) |
| macOS, Intel | [zCreator-osx-x64.zip](https://github.com/bogataj/zcreator-releases/releases/latest/download/zCreator-osx-x64.zip) |
| Linux | [zCreator-linux-x64.tar.gz](https://github.com/bogataj/zcreator-releases/releases/latest/download/zCreator-linux-x64.tar.gz) |

**Windows:** extract the zip and run `zCreator.exe`. To update, extract the new zip over your existing zCreator folder. Your own game data edits in `data/local` are kept.

**macOS:** the app is unsigned. After extracting, run `xattr -dr com.apple.quarantine zCreator.app` in Terminal once before opening it.

**Linux:** extract the archive and run `zCreator/ZCreator.Desktop`. It needs fontconfig, X11 (or XWayland) and OpenGL libraries.

The version you have is shown at the bottom of the **More** menu. Each release lists its changes on the [releases page](https://github.com/bogataj/zcreator-releases/releases). Click **Watch → Custom → Releases** on this page to be notified of new versions.
